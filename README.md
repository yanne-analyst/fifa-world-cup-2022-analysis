# ⚽ FIFA World Cup 2022 — Match Analytics

Data Analyst | AI-Augmented Data Analysis Project

## Overview
Full match-level analysis of all 64 FIFA World Cup 2022 matches, testing common football assumptions against the data — possession, shot efficiency, and confederation performance.

## Key Findings
- Possession doesn't predict winning: the team with more possession won only 49.0% of decisive matches — essentially a coin flip
- Shot efficiency is the real driver: teams with better shot-to-goal conversion won 77.6% of decisive matches
- CAF (Africa) outperformed UEFA (Europe) in win rate (40.0% vs 39.3%) despite fielding far fewer teams — reflecting Morocco's historic semi-final run
- Goal intensity peaked in the Final (6 goals on average), consistent with one of the most dramatic finals in World Cup history
